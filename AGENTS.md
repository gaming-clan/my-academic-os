# Udhëzime për punën në projekt

- Pas çdo ndryshimi në kod, dokumentacion ose konfigurim, krijo një commit të qartë dhe bëj push në branch-in aktiv.
- Përjashtim bëhet vetëm kur përdoruesi kërkon shprehimisht të mos bëhet commit ose push.
- Pas push-it, verifiko që branch-i lokal dhe ai remote janë sinkronizuar.
